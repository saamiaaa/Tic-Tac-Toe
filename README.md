# Tic Tac Toe 🎮

A fun and interactive Tic Tac Toe game built using **HTML, CSS, and JavaScript**. This project features a cute, playful interface with a clean design and engaging gameplay.

Players can take turns marking X and O on a 3×3 grid, with automatic win and draw detection. It also includes game reset functionality and a playful winning screen to make the experience more enjoyable.

**Technologies Used:**
- HTML5 – Game structure
- CSS3 – Styling, layout, and animations
- JavaScript – Game logic, player turns, and win detection
